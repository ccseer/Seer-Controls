# Seer Image Quantization - SPEC-003 Phase 0 Dataset

only) and `scripts/generate_animated_webp.py` (one animated WebP file, which
needs Pillow because the standard library has no WebP encoder). Both scripts
are deterministic, and every fixture is dedicated to the public domain
(CC0-1.0). The twelve non-synthetic fixtures below are transcribed from
`docs/dataset-real.json`, which `scripts/fetch_real_dataset.py` produces: eight
CC0-1.0 photographs from Wikimedia Commons and four UI fixtures drawn in code.

## Substitution under amended SPEC-003 section 9.3

9.3 was amended on 2026-11-04 (Appendix C r9) to accept a recorded CC0-1.0
substitute when a user-owned original cannot be supplied or licensed. The
package owner directed that all twelve slots be filled from CC0-1.0
public-domain sources and in-code UI fixtures, so the Phase 0 gate would not
stay blocked on assets that cannot be shot to order. The licence rule of 9.2
still governs and is satisfied as follows.

- Licence quoted: CC0 1.0 Universal public domain dedication, no attribution
  required, redistribution unrestricted, commercial use permitted.
- Access date: 2026-11-04 (UTC), recorded per file in `docs/dataset-real.json`
  together with the Commons file page.
- Verification: each run re-reads the Commons API `extmetadata.License` field
  and aborts on anything that is not exactly `cc0`, so a relicensed file can
  never re-enter the manifest unnoticed.
- Honest scope: these are recorded substitutes, not user-owned originals.
  CC0 disclaims copyright only: the portrait fixture shows
  an identifiable person, so it is committed strictly as a compression
  fixture and must not be reused as UI artwork, marketing material or
  in any published build.

Phase 0 exit gate, dataset item only: 12 of 12 slots are populated and 29 of
29 generated fixtures are present. This manifest claims nothing about the
other Phase 0 gate items (U3, U13, U14, U15, U20, the metrics self-check,
the bench CSV row, the WIC PoC result and the CI wiring); those live in the
Phase 0 report.
